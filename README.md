1. Масив з 10 цілих чисел заповнюється з клавіатури. Програма повинна 
видалити з масиву всі числа, більші за середнє арифметичне, і вивести на екран 
отриманий масив.

кількості стовпчиків. Програма повинна заповнити масив послідовно числами, 
починаючи з 1, по стовпчикам, починаючи з останнього.
